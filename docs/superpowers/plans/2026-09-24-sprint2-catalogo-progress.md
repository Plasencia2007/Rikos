  Ruling: BUG REAL — <Route path="*" element={<Navigate to="usuarios" replace />} /> en apps/admin/index.tsx (preexistente, no escrito en este sprint) usa una ruta relativa. En React Router, una ruta relativa en <Navigate> dentro de rutas anidadas se resuelve respecto a la URL NO coincidida, no a la base de las rutas -- con cualquier URL de mas de un segmento que no matchee (ej. /admin/catalogo/categorias si por cualquier razon no coincidiera), arma un bucle infinito de redirecciones que va acumulando "/usuarios" sin fin. Costo si el criterio fuera incorrecto: ninguno, una ruta absoluta en el comodín siempre es mas segura que una relativa en este contexto.
